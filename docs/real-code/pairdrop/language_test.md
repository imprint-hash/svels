# Language

## Switch the app to German
Click the "Set Language" button (the language icon in the top right corner).
Click the "Deutsch" button in the language list.
Verify the page shows the text "Öffne PairDrop auf anderen Geräten, um Dateien zu senden".

## Switch the app back to English
Click the language icon in the top right corner.
Click the "English" button in the language list.
Verify the page shows the text "Open PairDrop on other devices to send files".
